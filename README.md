# Sunny Gupta — Portfolio Website

A responsive, static portfolio site inspired by the visual language and five-theme switcher from the code shared for brand.io. It uses HTML, CSS, and vanilla JavaScript and is suitable for GitHub Pages.

## Files

- `index.html` — page content and theme switcher button markup
- `styles.css` — layout, responsive styles, and all five color palettes
- `theme-init.js` — applies a saved or default theme early to reduce theme flash
- `script.js` — theme cycling, cookie persistence, and subtle reveal animations

## Deploy to GitHub Pages

1. Upload these files to the root of your `sunnygupta007.github.io` repository.
2. In GitHub, open **Settings → Pages**.
3. Set the deployment source to **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to finish deploying. The site should be available at `https://sunnygupta007.github.io/`.

## Resume PDF (optional)

To add a resume download later, place a PDF in `assets/` and add a link to it in the hero or contact section. The current version does not include a resume download button because no PDF was supplied for this site.
